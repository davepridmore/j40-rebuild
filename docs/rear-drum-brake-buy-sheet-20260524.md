## Local-First Stop Before Import

The current engineering read is no longer purchase-released to a catalog wheel-cylinder kit from photos alone:

- The visible long cylinder in the May 24 photo is the drum-side barrel/boot view of a rear wheel cylinder.
- The loose replacement-cylinder photo shows the mounting/port side, so it naturally looks different from the installed drum-side view.
- Toyota EPC, Cruiser Corps, and FJParts still make the four-cylinder 9/1971-7/1980 rear axle layout a plausible reference.
- The user correctly challenged the visual mismatch; therefore no wheel-cylinder purchase is released until old samples or backside/port/mounting photos match.

Before paying for shoes or 3-inch/non-USA alternatives, still confirm shoe width:

1. If rear shoes are the usual narrow pre-8/1980 type, use local equivalents and treat Cruiser Corps `549-163` / `551-113` as reference numbers.
2. If rear shoes are **3 inch wide**, stop and use a matching local 3-inch non-USA rear brake route instead.

## Inspect Before Buying

| Item | Decision |
| --- | --- |
| Rear drums | Do not import by default and do not keep a pair order. Measure inside diameter and inspect scoring, cracks, heavy step, and out-of-round per side first. Split into side-specific machine/replace work only if inspection fails; otherwise mark the purchase redundant. |
| Adjusters | Clean and test first. Replace only if seized, rounded, badly pitted, or thread movement is rough. |
| Backing plates | Reuse unless cracked, bent, deeply grooved at shoe pads, or badly corroded. |
| Hubs/axle parts | Not part of the brake buy sheet unless bearing/seal inspection proves a fault. |

## Import Hold Rule

No expensive brake-part import is approved by default. If an import is later approved, group small high-value brake parts into one tracked courier shipment. Use DHL, UPS, or FedEx rather than ordinary post where possible. Do not import heavy drums unless measured inspection proves they are needed and local machining/replacement is rejected.
