# Brake Runner Spec Capture - 2026-05-28

Use this when a brake item is `runner_spec_controlled`. The goal is to remove judgement from the runner: the mechanic/user captures the spec, then Aamir either buys the exact match or sends photos/price and waits.

## Capture Kit

- Phone camera with flash.
- Tape measure or steel ruler.
- Calipers if available.
- Marker, masking tape labels, and small bags.
- One clean table/background for removed parts.

## General Rule

For every sample-controlled brake part:

- Photograph it installed before removal.
- Label the position before removal: `front left`, `front right`, `rear center`, `rear left`, `rear right`, `top`, `bottom`, `leading`, `trailing`.
- Photograph the removed part on a ruler.
- Photograph every end/clip/thread/seat close-up.
- Bag old samples by position and keep them until the new part is fitted.
- If a measurement cannot be captured, Aamir gets quote/photos only; no payment.

## Existing Rear Back-Section Photos

The rear back-section photo set already covers much of the installed context:

- Rear parking-brake cable route along the axle and backing plates.
- Backing-plate lever entry, external cable spring, retaining bracket, and clip area.
- Rear center hose/T-union and hard-line routing over the axle.
- Wheel-cylinder hard-line entry and backing-plate hydraulic context.
- Equalizer/intermediate cable routing and chassis/axle clearances.

Use those photos as route and layout evidence. Do not re-shoot the same views unless a supplier asks. The remaining release gap is scale and sample data: ruler/caliper measurements, labelled old parts, and received-cable comparison.

## Brake Flex Hose Spec

Capture one card per hose: front-left, front-right, and rear-center.

Required photos:

- Whole installed hose route. The existing rear back-section photos cover much of the rear-center route.
- Chassis/bracket end close-up with retaining clip visible.
- Caliper, axle, or T-fitting end close-up. The existing rear photos show the rear axle/T area; final release still needs the old hose or a measured end close-up.
- Removed hose laid straight beside a ruler.
- Hose marking/rating, if readable.
- Any sleeve, spring guard, locating tab, grommet, or bracket groove.

Required measurements:

- Free length of the flexible hose between metal end fittings.
- Overall length end-to-end.
- End A type and End B type: male, female, banjo, bulkhead, or special fitting.
- Thread size and pitch if known, for example `M10x1.0`; otherwise photograph thread beside ruler and use a pitch gauge if available.
- Seat/flare type at hard-line connection if visible.
- Banjo bolt diameter and sealing-washer size if any hose uses banjo fittings.
- Bracket groove width and clip slot thickness.
- Any fixed clocking/orientation between the two ends.

Release rule for Aamir:

- He may buy only complete crimped automotive brake hose assemblies matching this card or the labelled old sample.
- Hose must be marked or sold as brake-fluid rated, `DOT/SAE J1401` or OEM-equivalent.
- Reject generic rubber hose cut from roll, reused hose, unmatched ends, unknown rating, or seller-suggested substitute fittings.

## Rear Drum Spring / Hold-Down / Adjuster Spec

Capture after opening the drum, before removing the spring layout.

The existing rear drum/backing photos count as layout evidence, but the hardware purchase still needs either the opened-drum layout with enough detail or the old spring/hold-down/adjuster pieces bagged and labelled.

Required photos:

- Straight-on photo of each complete opened drum before touching springs.
- Close-up of upper spring area.
- Close-up of lower spring/adjuster area.
- Close-up of each hold-down pin, cup, and spring.
- Parking-brake lever and retaining clips.
- All removed springs/hardware laid out in the same layout as fitted.

Required measurements:

- Shoe width and approximate drum internal diameter, if easy to capture.
- Return spring free length, wire diameter, hook shape, and which hole each end uses.
- Hold-down pin length and head style.
- Hold-down spring length/diameter and cup diameter.
- Adjuster length, star-wheel style, thread direction, and left/right difference.
- Any special retaining clips, washers, or parking-brake lever clips.

Release rule for Aamir:

- First check the PakWheels shoe delivery for included matching hardware.
- If hardware is not included, Aamir may buy only a kit that matches the opened-drum photos/spec or the bagged old samples.
- If left/right adjusters differ, do not accept a one-side-only substitute as a full axle kit.

## Rear Parking-Brake Attachment Hardware Spec

Use the received cable, old cable, and backing-plate/equalizer hardware as the samples.

The existing rear back-section photos already cover the installed route and external backing-plate lever/return-spring area. Finish the spec by comparing the received cable to the old cable and measuring or bagging the small attachment pieces.

Required photos:

- Cable end at backing plate before removal.
- Cable end at equalizer/intermediate connection.
- Clevis/equalizer/adjuster hardware laid out with ruler.
- Clips, pins, return springs, and cable-end retainers close-up.
- Received cable package contents.

Required measurements:

- Clevis pin diameter and usable length.
- Clip type: R-clip, cotter pin, circlip, hairpin, or spring clip.
- Adjuster nut thread size/pitch if known.
- Return spring free length, wire diameter, and hook shape.
- Cable-end barrel, clevis, or eye dimensions.
- Equalizer plate hole sizes and spacing if a plate is missing or worn.

Release rule for Aamir:

- Do not buy duplicates already included with the received cable.
- Aamir may buy only hardware matching the received cable plus old sample/spec.
- If the seller changes clevis/equalizer style, collect photos and price only.
