# Naturally Aspirated Cooling Compact Mounts — Rev N

This controlled handoff adds the compact removable X2-L/X2-R crossmember-end brackets and enumerates every cooling-pack mounting fabrication. It does **not** release final cutting or drilling.

## Controlled load path

`R0 → R1 lower saddles → X1 seats → X0 crossmember → X2-L/X2-R removable end brackets → accepted existing LH/RH structural pickups`

Upper T0 ears locate only. C1, F1, F2 and G1 are independent. E1 carries electrical protection only.

## Critical mounting-size rule

X2 must terminate at the smallest structurally released fastener/load/gusset/tool/drainage envelope. Do not extend it into cosmetic long arms. The existing July-welded uprights remain untouched unless U0 plus a written competent-person release explicitly identifies a projection as non-structural surplus and controls the cut/repair/finish.

## Handoff sequence

1. Complete `measurement_basis.csv` from the actual chassis and retained parts.
2. Inspect and record both existing upright parent sections, weld toes and HAZ.
3. Produce rigid B0, S0 and mirror-handed U0 templates.
4. Calculate and draw X0/X1/X2/T0 for all required road-load, shock, vibration and fatigue cases.
5. Mock up X2 locally; prove fastener tool sweep, drainage and removable X0 without altering the upright.
6. Dry-fit the full real pack and freeze all independent carrier drawings.
7. Fabricate only from signed released drawings. Mark parts by reference and hand.
8. After structural release, apply a total static proof load of 2 × MR, distributed between the two S0 saddle centres in the released loaded-radiator distribution, for 10 minutes. Use the released fixture/distribution so the rubbers and crossmember are not point-loaded.
9. Complete `inspection_checklist.csv`, coat, assemble and commission under the Rev N guide.
